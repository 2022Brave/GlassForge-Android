# GlassForge Android

Native Android starter for Liquid Glass-inspired home-screen widgets.

## Build APK
Every push to `main` runs Android CI. Download `glassforge-debug-apk` from the workflow's Artifacts section.

Includes a Compose studio UI and native clock/battery widgets. Android RemoteViews widgets can approximate translucent glass but cannot render arbitrary live backdrop refraction. Validate on Samsung and Motorola launchers.
